🏗️ 2. Məhsulun Arxitekturası və İş Prinsipi

Məhsul tək bir müstəqil (Single File) veb-tətbiq kimi hazırlanmışdır və 3 əsas ekrandan (moduldan) ibarətdir:

🟢 2.1. Qarşılama Ekranı (Welcome Screen)

Vizual Identiklik: Klubun rəsmi logosu, modern yaşıl-pastel tonlar və animasiyalı arxa fon elementləri.

Giriş İnputu: Tələbənin tam adını daxil etməsi üçün sahə (validation ilə).

Liderlər Lövhəsi Düyməsi: Ən yüksək nəticələri göstərən modala sürətli keçid.

🟡 2.2. Oyun Mexanizmi (Quiz Engine)

Sual Bazası: Ekologiya, 3R konsepti, karbon izi və e-tullantılar üzrə 15 xüsusi hazırlanmış interaktiv sual.

Dinamik Taymer: Hər sual üçün 20 saniyəlik geri sayım. Son 5 saniyədə vizual "pulse" xəbərdarlığı.

Kombo və Bonus Mexanizmi: Ardıcıl düzgün cavablar verdikdə işə düşən "Combo Multiplier" (x2, x3 və s.) animasiyası.

İzahlı Əks-Əlaqə: Cavab seçildikdən dərhal sonra açılan maarifləndirici məlumat qutusu (Explanation Box).

Səs Effektləri: Web Audio API vasitəsilə sintez olunmuş düzgün və səhv cavab səs siqnalları.

🔴 2.3. Nəticə və Təhlil Ekranı (Result & Analytics)

Statistika Bloku: Ümumi xal, düzgün/səhv cavab sayı və maksimum kombo göstəricisi.

Eko-Status Təyini: Toplanan xala əsasən iştirakçıya verilən rəsmi ünvanlar:

🌿 90%+ : Eko-Ekspert

🌱 60%-89% : Eko-Həvəskar

🍃 35%-59% : Eko-Tələbə

🌍 0%-34% : Eko-Yolun Başlanğıcında

Təhlil Pəncərəsi (Review Modal): Səhv cavablandırılmış sualların izahı ilə birgə təkrar nəzərdən keçirilməsi.

Liderlər Lövhəsi (Leaderboard Modal): Ən yaxşı 10 nəticənin brauzerin daxili yaddaşında (localStorage) saxlanılması.
