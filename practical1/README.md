📝 Layihə Haqqında

Eco-Quiz — tələbələrin ekologiya, yaşıl texnologiyalar, tullantıların idarə olunması və karbon izi kimi vacib ekoloji mövzularda biliklərini yoxlayan, interaktiv və əyləncəli mini veb-oyundur.

Layihə Cahandar Məcidlinin rəhbərliyi ilə IT Departamentinin verdiyi 1-ci praktiki tapşırıq çərçivəsində hazırlanıb və qalib layihə seçilib. Məhsul tam olaraq mobil və masaüstü cihazlara uyğundur (Responsive), audio effektlərlə zənginləşdirilmişdir və dinamik qiymətləndirmə mexanizminə malikdir.

✨ Əsas Xüsusiyyətlər (Features)

👤 İstifadəçi Qeydiyyatı: Oyunçunun ad və soyadı ilə daxil olması.

⏱️ Taymer Sistemi: Hər sual üçün 20 saniyəlik dinamik vaxt məhdudiyyəti.

🎵 Səs Effektləri: Düzgün və səhv cavablar üçün xüsusi Web Audio API səs effektləri.

🔥 Kombo Mexanizmi: Ardıcıl düzgün cavablar zamanı bonus xalların və kombo animasiyasının işə düşməsi.

📊 Ətraflı Nəticə və Təhlil:

Düzgün, səhv cavabların və maksimum kombonun göstərilməsi.

Cavabların izahlı təhlili siyahısı (Review Mode).

🏆 Liderlər Lövhəsi (Leaderboard): Ən yüksək xal toplayan iştirakçıların localStorage vasitəsilə saxlanılması və nümayişi.

🎖️ Dinamik Statuslar: Xala uyğun olaraq Eko-Ekspert, Eko-Həvəskar, Eko-Tələbə və ya Eko-Yolun Başlanğıcında statuslarının verilməsi.

🛠️ Texnoloji Stack

Frontend: HTML5, CSS3 (Custom Variables & Animations)

Scripting: JavaScript (Vanilla JS - ES6+)

Icons & Fonts: FontAwesome 6, Google Fonts (Outfit)

Audio: Web Audio API (Sintez olunmuş səs effektləri)

Data Storage: localStorage (Liderlər lövhəsi üçün)
